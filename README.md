# 🔐 Password Strength Analyzer

A Python-based cybersecurity project that analyzes the strength of a password and helps users create stronger passwords.

## 📌 About the Project

The Password Strength Analyzer is a desktop application developed using Python and Tkinter.

The application checks a password based on five basic requirements:

- Uppercase letters
- Lowercase letters
- Numbers
- Special characters
- Minimum length of 8 characters

Each requirement gives one point, resulting in a maximum score of 5.

The application then displays the password strength based on the score.

## ✨ Features

- 🔐 Password strength analysis
- 📊 Strength score out of 5
- ✓ Password requirement checking
- 🔑 Strong password generator
- 👁 Show/Hide password
- 🖥 Simple graphical user interface

## 🛠 Technologies Used

- Python
- Tkinter
- Random module
- String module
